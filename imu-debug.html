1. 连接体感控制器

用手机（推荐先用它测试）

手机打开：获取地址中…
  1. 手机和这台 Mac 连同一个 Wi-Fi。
  2. 扫码：iPhone 用相机；安卓用 Chrome 或系统浏览器的扫一扫（不要用微信扫）。
  3. 出现「连接不是私密连接」时：iPhone 点「显示详细信息 → 访问此网站」，安卓 Chrome 点「高级 → 继续前往」。
  4. 点「开始」；iPhone 会询问「动作与方向」，选「允许」。
  5. Mac 如果弹出「是否允许 node 接受传入的网络连接」，选「允许」。

用 Joy-Con

  1. 在 Mac 的「系统设置 → 蓝牙」里配对：按住 Joy-Con 导轨侧面的小圆形配对键，直到指示灯来回闪烁，然后在列表里点「连接」。
  2. 点下面的按钮，在弹出的窗口里选择 Joy-Con。授权一次后，刷新页面会自动连上。
  3. 建议戴好 Joy-Con 腕带。

2. 校准与回中

回中：手机顶端（或 Joy-Con 肩键一端）指向屏幕，点按钮，或按手机上的「回中」/ Joy-Con 的 Y、↑ 键。

3. 实时数据

陀螺仪（度/秒）
加速度（g）
角速度大小（弧度/秒），黄线 = 录制时的挥拍提示

4. 姿态

Joy-Con：红色方块，白色面是按键面，黑色一端是肩键。手机：深蓝色是屏幕，黑色小条在顶端。坐标轴：红 X、绿 Y（指向屏幕）、蓝 Z（向上）。

5. 检查清单

六个面静止（|a| 应为 1.00 ± 0.02 g）

把手机（或手柄）依次以 6 个面朝上放稳 1 秒。

陀螺仪 / 加速度计方向一致性

拿着手柄朝各个方向慢慢转动（不要甩），直到进度满。

静止偏航漂移（Joy-Con 应 < 2°/分钟，手机 < 5°/分钟）

平放校准后放着不动至少 10 秒。
