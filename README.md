# 体感乒乓（Rea-Sports）

用手机或 Switch 一代 Joy-Con 当球拍、在电视上玩的体感乒乓球，手感对标 Wii Sports Resort 的乒乓球。
净室重做：只复刻玩法机制，不使用任天堂的任何代码、素材、名称或音乐。

## 在线版（不用装任何东西）

- 首页：https://daiwang-lei.github.io/Rea-Sports/
- 和电脑对打：https://daiwang-lei.github.io/Rea-Sports/?mode=match
- 发球机练习：https://daiwang-lei.github.io/Rea-Sports/?mode=practice
- 体感调试页：https://daiwang-lei.github.io/Rea-Sports/imu-debug.html

在线版里，手机用 **WebRTC 直连**电脑：只有「握手」消息经过公共免费的 MQTT 服务器（EMQX，国内节点优先），
体感数据在同一 Wi-Fi 里由手机直接发给电脑，延迟和本地一样。用法：

1. 电脑打开在线版的体感调试页，页面上会显示**房间号**和二维码。
2. 手机连同一个 Wi-Fi，扫码（iPhone 用相机，安卓用 Chrome 或系统浏览器，不要用微信扫），点「开始」。
3. 正规证书，不会再出现「连接不是私密连接」；也不用开 Mac 上的开发服务器。

说明：

- 握手消息在公共服务器上是公开可见的，所以房间号是随机生成的 8 位字母数字；里面只有建立连接用的信息，没有体感数据。
- 极少数路由器（开了「AP 隔离」或屏蔽组播）会让直连失败，这时改用下面的本地模式。
- 每次推送到 main，GitHub Actions 会自动跑检查、构建并发布（`.github/workflows/deploy.yml`）。

## 运行

```bash
pnpm install
pnpm dev          # 打开 https://localhost:5288
```

- 开发服务器用 **https**（手机浏览器只有在安全连接下才给体感数据），证书是自签名的：第一次打开时浏览器会提示「连接不是私密连接」，在 Mac 的 Chrome 里点「高级 → 继续前往」即可。
- 端口固定为 5288（WebHID 的授权按网址记忆，端口变了要重新授权）。电脑上请用 **桌面版 Chrome**。
- 服务器监听局域网，同一 Wi-Fi 下的手机才能连上来。

| 页面       | 地址                                  | 用途                                                               |
| ---------- | ------------------------------------- | ------------------------------------------------------------------ |
| 菜单       | https://localhost:5288/               | 入口                                                               |
| 和电脑对打 | https://localhost:5288/?mode=match    | 5 个等级的电脑对手，6 分或 11 分一局，自己发球、记分、结算         |
| 发球机练习 | https://localhost:5288/?mode=practice | 用手机 / Joy-Con / 键盘挥拍回球，每球给出时机、正反手、力度、旋转  |
| 体感调试页 | https://localhost:5288/imu-debug.html | 连接手机或 Joy-Con、看数据、检查清单、震动、录挥拍样本、看挥拍识别 |
| 手机控制器 | 扫调试页上的二维码                    | 手机当球拍                                                         |
| 自动演示   | https://localhost:5288/?mode=autoplay | 电脑对电脑，看物理/规则/AI/画面/声音                               |

自动演示的参数：`a`、`b` = 两边电脑等级 1–5，`points` = 6 或 11，`speed` = 速度倍率（如 0.3 慢放），`seed` = 随机种子，`skip` = 开局先快进的秒数。

## 用手机当球拍（iPhone / 安卓）

1. 手机和 Mac 连**同一个 Wi-Fi**（访客网络、开了「AP 隔离」的路由器连不上）。
2. Mac 上打开体感调试页，用手机扫页面上的二维码：iPhone 用相机；安卓用 Chrome 或系统浏览器的扫一扫。**不要用微信扫**。
3. 手机会提示「连接不是私密连接」（自签名证书）：
   - iPhone（Safari）：点「显示详细信息 → 访问此网站 → 访问网站」。
   - 安卓（Chrome）：点「高级 → 继续前往」。其他浏览器类似，找「继续访问」。
4. 点「开始」。iPhone 会询问「动作与方向」权限，选「允许」。然后把手机**屏幕朝上平放**一两秒，自动判断方向。
5. Mac 第一次可能弹出「是否允许 node 接受传入的网络连接」，选「允许」。
6. 握法：竖着握住手机下半部分，像握球拍柄一样，拇指放在「确认 / 抛球」大按钮上。**握紧、最好挂手机绳**，先小幅度轻挥。

手机采样约 60 次/秒（Joy-Con 约 200 次/秒），足够测试功能；安卓 Chrome 支持震动反馈，iPhone 浏览器不支持震动。

## 发球机练习怎么玩

1. 打开发球机练习，扫码连手机（或点「连接 Joy-Con」，没有设备可以先用键盘：F 正手、J 反手）。
2. **校准（指向电视，和 Switch 一样）**：设备就是球拍——Joy-Con 肩键一端（手机顶端）是拍头，按键面（屏幕）是正手面（红面）。
   - Joy-Con：**按键面朝上平放在桌上、肩键一端指向电视，按住 X + R**（Joy-Con L：↑ + L），放稳约 2 秒：
     同时测陀螺仪零点、定下电视方向。之后任何时候平放在桌上按住 X + R 都能重新校准；平放不动时零点也会自动重测。
   - 手机：屏幕朝上放平、顶端指向电视，按「确认」。
   - 打球中觉得拍子方向偏了：把拍头像遥控器一样指向电视，按「回中」（Joy-Con 的 Y 键）。
     等球时拿稳不动，游戏会自动去掉陀螺仪漂移：校准后先记住你平时准备姿势的拍面角度，之后一直保持这个角度。
   - 也可以跳过，只是不判断拍面角度。
3. 发球机开始送球。球在你这边弹起、来到身前时挥拍：
   - 右手正手从右往左挥，反手从左往右挥（左手相反，暂停菜单里可以切换）；
   - **早挥打斜线、晚挥打直线**，太早 / 太晚会挥空，在球弹起之前就打到算「未落台击球」；
   - 挥得越快球越快；拍面前压或由下往上刷 → 上旋，拍面后仰或由上往下切 → 下旋；
   - 每一球右上角都有结果卡片：早 / 晚多少毫秒、正反手、力度、球路。
4. 暂停（手机「暂停」/ Joy-Con + / Esc）里可以调难度、落点、宽容度、画面延迟补偿；
   打满 5 球后可以「按我的平均时机校准」，把电视的画面延迟补回来。

## 和电脑对打怎么玩

1. 打开「和电脑对打」，连接设备、校准（平放指向电视按住 X + R），和发球机练习一样（见上）。
2. 选对手（入门 → 冠军 5 个等级）和分制（6 分；11 分球更快），按 A（手机「确认」/ Enter）开始。
   Joy-Con 上只能按 A 用上次选的对手开始，换对手要用鼠标点或键盘 ← →。
3. **发球**：轮到你发球时（右下角有提示），按 A（手机「确认」、键盘空格）或**向上抖一下手柄**把球抛起来，
   抖得越用力抛得越高；球落下时挥拍。时机和回球一样：早打斜线、晚打直线；挥得越快发得越长越快，拍面定旋转。
   发出的球一定先落本方台再过网；没打到的话球落下后再抛一次，不罚分。
4. 回球和发球机练习一样。每次击球后屏幕下方有小字提示时机（如「正手 · 早 35ms」），暂停菜单里可以关。
5. 比分只在两分之间显示（和 WSR 一样）。每人连发 2 球，先到 6（11）分并领先 2 分获胜，20 平算平局；
   两分之间按 A 可以跳过停顿。打完出结算页：比分、回合长度、双方各怎么失分、你的回球时机。
6. 暂停（手机「暂停」/ Joy-Con + / Esc）：正在打的这一分作废，继续后重打。手柄断开或没有数据时会自动暂停。
   暂停菜单里可以调宽容度、画面延迟补偿（和练习共用，按屏幕记）、持拍手、时机提示，也可以「录制这局」：
   这一局打完或 10 分钟自动停止并下载，用 `pnpm analyze:practice` 分析。

## 连接 Joy-Con（macOS）

1. 「系统设置 → 蓝牙」；按住 Joy-Con 导轨侧面的小圆形配对键，直到指示灯来回闪烁，在列表里点「连接」。
2. 打开体感调试页，点「连接 Joy-Con」，在弹窗里选中手柄。以后刷新页面会自动连上。
3. Joy-Con 重新插回 Switch 时会自动和 Switch 配对，再用于电脑时要重新做第 1 步。
4. 建议戴好腕带。

## 接电视

- MacBook 用 HDMI 线接电视（镜像显示，或把电视设为主显示器）。
- 电视切到「游戏模式」，关闭「运动补偿 / MEMC / 动态清晰」等画面增强（会增加延迟）。
- Chrome 全屏：⌃⌘F。

## 开发命令

```bash
pnpm test           # 单元测试（物理、求解器、规则、记分、输入解析、融合、诊断……）
pnpm typecheck      # 类型检查（含「纯逻辑层不得依赖 DOM」的检查）
pnpm lint
pnpm soak --games 200 --a 3 --b 3 --points 6   # 无界面批量对局统计
pnpm bench:solver   # 求解器性能
pnpm smoke:phone    # 冒烟测试：模拟一台手机经本地中转发数据给调试页（需先 pnpm dev）
pnpm smoke:rtc [网址]  # 冒烟测试：两个浏览器页面经 WebRTC 直连（默认本地；也可传线上网址）
pnpm smoke:mqtt     # 测试公共 MQTT 握手服务器能否连通
pnpm smoke:practice [网址]      # 发球机练习冒烟测试：键盘模式按时机自动挥拍
pnpm smoke:practice-phone       # 模拟一台手机放平指向电视校准 → 挥拍回球 → 录制下载（需先 pnpm dev）
pnpm smoke:practice-joycon      # 模拟一台 Joy-Con 平放指向电视、按住 X + R 校准 → 挥拍回球（需先 pnpm dev）
pnpm smoke:match [网址]         # 比赛冒烟测试：键盘模式打完一整局（中途暂停一次），出结算页
pnpm smoke:match-joycon         # 模拟一台 Joy-Con：向上抖手柄抛球 → 发球 → 回球 → 录制下载（需先 pnpm dev）
pnpm analyze:practice xxx.json  # 分析「录制这局」的文件（练习逐球、比赛逐分）
pnpm analyze:imu fixtures/imu/xxx.json   # 分析录制：采样率、丢包、蓝牙延迟、挥拍
pnpm eval:swing fixtures/imu/xxx.json    # 在录制上跑挥拍识别
pnpm shot /phone.html out.png 390 844   # 截图（需先 pnpm dev）
pnpm build
```

## 目录

```
src/core/      数学（向量、四元数、可复现随机数）
src/config/    手感参数 tuning、电脑难度、震动预设
src/input/     Joy-Con（协议、校准、震动、WebHID 驱动）、手机（消息、坐标换算、接收）、时间戳、姿态融合、
               挥拍识别、抛球识别与球拍模型（paddle/）、诊断、录制回放
src/sim/       仿真（纯 TS）：球的物理、击球求解器、裁判与记分、走位、电脑 AI、整局比赛 MatchSim、
               玩家击球判定与映射（hit/HitResolver）、比赛里人的一方（players/HumanPlayer）、
               发球机练习（practice/FeederSim）
src/render/    three.js 画面：场地、球与影子、人物与球拍、相机
src/audio/     程序化音效
src/ui/        画面文字层（比分、提示）
src/app/       入口、自动演示、和电脑对打（match/）、发球机练习页（practice/）、
               两者共用的连接与校准、延迟补偿（shared/）、体感输入管理（input/）
src/debug/     体感调试页
src/phone/     手机控制器页
server/        开发服务器插件：手机数据的 WebSocket 中转、局域网地址
src/net/       极简 MQTT 客户端、WebRTC 握手约定
fixtures/imu/  真机录制（Joy-Con / iPhone 的正手提示音录制和自由挥拍），用于调参和回归测试
tests/         vitest 测试
scripts/       soak（批量对局）、bench-solver
```

`src/core`、`src/sim`、`src/input` 里的纯逻辑部分不依赖浏览器（由 `tsconfig.sim.json` 和 ESLint 强制），
以后做安卓电视 App 时可以直接复用。
